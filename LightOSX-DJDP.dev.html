MIDI control

Map any button, slider, fader, dropdown or pad to a MIDI note or CC. Press Learn mode, click a control anywhere in the app (switch tabs freely), then move a knob or press a key on your controller. Esc leaves learn mode. Notes act as buttons, CCs work as faders or buttons (127 = pressed).

Settings file

All settings (patch, pads, MIDI map, DMX interface, audio device) are stored in one JSON file you choose. If the file is missing, LightOSX creates a new one at the next Create / Reconnect and reads from it on every start. Settings are also cached in the browser as a safety net.

DMX interfaces & universes

Connect several interfaces at once and give each its own universe (1–8). Fixtures patched above address 512 live in the next universe automatically. Break/MAB timing and frame size are in the footer.

Art-Net / eDMX: browsers cannot send UDP, so a tiny helper relays frames from this app to the network. then run python3 bridge.py (Python 3, any OS, no installs). Set the target node IP (or broadcast) and Art-Net universe on the interface row.
